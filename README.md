# Buck-Boost 双闭环仿真 GUI

这是一个纯 Python 的四开关非反相 Buck-Boost 平均模型仿真器。它可以在同一组功率级与扰动条件下，对比：

- 单电压 PID；
- 工业电源常用的外电压 PI + 内电流 PI 级联控制；
- 输入电压/目标电压前馈；
- 软启动、电流限幅、占空比限幅与积分抗饱和；
- Buck/Boost 交界区的平滑调制。
- RoboMaster 车辆动态功率负载与超级电容双向削峰填谷。

在纯 Boost 区，Buck 桥臂显示 100% 表示该桥臂保持静态导通；`PWM 最大占空比`只限制实际进行 PWM 的桥臂。

## 运行

```powershell
python -m pip install -r requirements.txt
python main.py
```

GUI 启动后可修改功率级、控制器和负载/输入阶跃参数。选择两种策略分别运行，即可看到输出电压、电感电流与两桥臂占空比的差别。结果也可导出为 CSV。

左侧参数区使用“电路 / 控制器 / 车辆负载 / 公式”四个选项卡。“公式”页包含平均模型、稳态变换比、级联双环公式和 Buck/Boost 连续切换图，红色标记会跟随当前工况移动。右侧电路图中的输入源、目标电压、电感、电容、负载、限流值和 PWM 上限均可双击修改，并会与左侧参数保持同步。

右侧结果区提供“时域波形”和“稳态电压－占空比”两个选项卡。稳态页同时显示 Buck/Boost 理想电压曲线、目标电压交点、双桥过渡区以及指定稳定电压对应的两个桥臂占空比。

## 为什么单 PID 常常“不够”

Buck-Boost 的控制对象会随工作点变化：降压区和升压区的占空比增益不同，Boost 区还存在右半平面零点。负载、电感电流和输入电压变化后，同一组电压 PID 参数很难同时保证速度、稳定性与限流。级联结构用快速电流内环约束电感能量，再由较慢的电压外环给出电流目标；这是数字电源和电机控制器更常见的组织方式。

## 模型边界

当前模型是连续导通模式（CCM）的开关周期平均模型，适合控制结构和参数趋势验证，不用于器件损耗、MOSFET 死区、开关纹波、磁芯饱和或环路最终认证。上硬件前仍需基于实际采样频率、延迟、传感器比例和功率级小信号模型重新整定，并完成限流/过压等独立保护。

普通稳压模式是“左侧直流源 → 四开关变换器 → 右侧电容与阻性负载”的模型。RoboMaster 并联式超级电容系统使用相同的四开关功率级，但系统连接和控制目标不同：底盘电机与电源位于母线侧，变换器另一端连接超级电容组，核心闭环是可正可负的电感电流/功率控制，用于削峰填谷，而不是把右侧当普通阻性负载进行输出稳压。

GUI 现在同时提供两种应用模式，并默认进入“RoboMaster 车辆功率控制”。文档已经按编号整理，入口见 [docs/README.md](docs/README.md)。
