## 2. 推荐阅读顺序

第一次了解系统时，按 `1 → 2 → 3` 阅读：

1. 先明确 RoboMaster 超级电容在车辆上的连接方式和功率控制目标；
2. 再沿“功率 → 电流 → 比例指令 → 两桥占空比”理解换算，区分 FPWM、PWM 频率和模式状态机；
3. 最后在 GUI 中修改车辆负载、超级电容和控制器参数进行验证。

第 4、5 篇属于进阶资料：第 4 篇区分启动暂态、动态平均模型和稳态公式；第 5 篇列出从仿真走向硬件产品所需的工程工作。

## 3. 如果卡在“控制的是 PWM，为什么还要换算”

直接阅读第 2 篇的第 1～6 节，其中用 24 V / 18 V、36 W 的例子走完计算过程。第 7 节解释旧文档里的 x，它是另一种教学坐标，当前代码无需经过 x。

## 4. 当前实际实现

Python 平均模型使用“功率指令 + 双向电流 PI + 电压比前馈 + 模式状态机 + 两桥占空比映射”。PI 修正的是变换比指令 M，调制器再生成占空比。FPWM 是工作模式术语，与状态机不是二选一；当前模型不模拟具体芯片的 FPWM/PFM 切换，也不生成真实定时器脉冲。
