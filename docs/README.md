## 2. 推荐阅读顺序

第一次了解系统时，按 `1 → 2 → 3` 阅读：

1. 先明确 RoboMaster 超级电容在车辆上的连接方式和功率控制目标；
2. 再理解四开关变换器如何使用 FPWM 或模式状态机产生 PWM；
3. 最后在 GUI 中修改车辆负载、超级电容和控制器参数进行验证。

## 3. 当前方案建议

RoboMaster 超级电容优先采用“FPWM 统一调制 + 双向电流闭环 + 功率指令”的结构。显式模式状态机作为高效率控制方案和对照方案保留，不让 PID 直接控制 MOS 开关组合。
