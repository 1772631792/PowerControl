## 2. 启动程序

```powershell
python main.py
```

也可以双击工程根目录中的 `启动仿真.bat`。

## 3. 选择应用模式

GUI 左侧顶部提供两种应用：

1. `RoboMaster 车辆功率控制`：默认模式，控制电源侧功率；
2. `普通 Buck-Boost 输出稳压`：用于对比单电压 PID 和电压、电流双闭环。

## 4. 设置车辆负载

打开“车辆负载”选项卡，可设置：

- 裁判系统功率上限；
- 车辆初始功率；
- 车辆功率阶跃时刻；
- 阶跃后车辆功率；
- 仿真总时间。

车辆功率低于限制时，剩余功率给超级电容充电；车辆功率高于限制时，超级电容放电补偿。

## 5. 设置超级电容

同一选项卡中可以设置：

- 超级电容初始电压；
- 最低允许电压；
- 最高允许电压；
- 超级电容容量。

车辆负载还提供以下动态参数：

- 车辆响应时间常数：模拟电机、电调和机械系统不会瞬间改变功率；
- 功率采样滤波：模拟 ADC 与数字低通滤波延迟；
- 动态波动幅值与频率：模拟车辆运动中的周期性功率变化；
- 电流参考斜率：限制功率阶跃时的电感电流变化速度。

“电路”选项卡中可以设置母线电压、电感、电流限制和 PWM 最大占空比。

“控制器”选项卡中的默认控制计算频率为 1000 Hz。所有 Ki 均为每次控制循环的离散积分增益，控制代码使用 `积分值 += Ki × 误差`，不会再次乘以 `dt`。修改控制频率后需要重新整定 Ki。控制计算频率不等于 MOS PWM 载波频率；实际 PWM 应保持更高频率。

## 6. 查看波形

右侧选择“时域波形”，可以查看：

- 车辆功率；
- 裁判系统看到的电源输入功率；
- 功率限制；
- 电感实际电流和目标电流；
- 超级电容电压；
- 左右桥臂占空比。

## 7. 查看稳态曲线

右侧选择“稳态电压－占空比”，可以查看：

- Buck 稳态电压曲线；
- Boost 稳态电压曲线；
- 当前稳定电压；
- 两侧桥臂所需占空比；
- Buck/Boost 连续调制过渡区。

功率控制模式不会把超级电容电压闭环稳定在固定值。该页面显示的是当前两侧电压对应的调制前馈关系。
