# 双向四开关 Buck-Boost 工程技术体系

## 1. 文档定位

本文从产品开发角度整理母线与超级电容之间的四开关、单电感、双向 Buck-Boost 变换器。它是工程路线图，不表示当前 Python 平均模型已经实现所有功能。

完整工作可分为六层：

1. 电力电子基础：MOS、电感、电容、能量流动、KCL 和 KVL。
2. 数学建模：分段模型、平均模型、稳态、小信号和损耗模型。
3. PWM 与模式管理：Buck、Transition、Boost、同步整流和双向运行。
4. 闭环控制：电流 PI、电压或功率外层、前馈、限幅和离散化。
5. 工程保护：预充、软启动、过流、死区、故障恢复和热设计。
6. 仿真与验证：启动、模式切换、效率、EMI 和最坏工况。

## 3. 数学模型

### 3.1 状态与输入

对于双向四开关拓扑，可定义：

$$
x=
\begin{bmatrix}
i_L\\V_{bus}\\V_{cap}
\end{bmatrix},
\qquad
u=
\begin{bmatrix}
D_L\\D_R
\end{bmatrix}
$$

忽略开关损耗，并假设两侧具有滤波电容，可建立平均模型：

$$
\begin{cases}
L\dot i_L=D_LV_{bus}-D_RV_{cap}-R_Li_L\\[5pt]
C_{bus}\dot V_{bus}=i_{source}-i_{load}-D_Li_L\\[5pt]
C_{cap}\dot V_{cap}=D_Ri_L-i_{cap,external}
\end{cases}
$$

模型中占空比与状态量相乘，因此全工况平均模型不是线性系统。

### 3.2 开发中需要的模型

| 模型 | 主要用途 |
|---|---|
| 四开关分段模型 | 研究瞬时开关过程和电流纹波 |
| 周期平均大信号模型 | 研究启动、功率变化和控制动态 |
| 稳态工作点模型 | 求占空比、电流和损耗关系 |
| 小信号线性模型 | 设计 PI、分析带宽和稳定性 |
| 离散控制模型 | 分析 ADC、PWM、计算延迟和控制周期 |
| 非理想模型 | 研究导通电阻、死区、电感 DCR 和寄生参数 |

启动暂态、平均模型和稳态公式之间的关系，见 [启动暂态、平均模型与稳态分析](04_启动暂态与稳态分析.md)。

## 4. PWM 与模式管理

### 4.1 调制模式

两个半桥共享一个电感。Buck 区主要调制左桥，Boost 区主要调制右桥，电压比接近 1 时协调两个桥臂。具体占空比定义和当前代码的映射，见 [FPWM、PWM 占空比与模式状态机](02_FPWM与模式状态机.md)。

当前模式状态机使用以下默认阈值：

| 切换方向 | 实测电压比阈值 |
|---|---:|
| Buck → Transition | 0.90 |
| Transition → Buck | 0.86 |
| Transition → Boost | 1.10 |
| Boost → Transition | 1.06 |

另有 2 ms 最小驻留时间。这些设置用于减少边界抖动，仍需在开关级仿真和硬件上验证切换瞬态。

### 4.2 平滑切换

模式切换需要共同处理：

- 两桥占空比和开关时序的连续性；
- PI 积分状态跟踪和调制增益变化；
- 占空比、最小脉宽和峰值电流约束；
- ADC 采样位置与开关纹波变化；
- 硬件保护和故障关断时序。

当前代码已有积分状态重置和模式范围约束，这是平均模型层面的处理。它不能代替实际 MOS 驱动和电感电流的切换测试。

### 4.3 三个独立维度

| 维度 | 典型状态 |
|---|---|
| 调制模式 | Buck / Transition / Boost |
| 能量方向 | 充电 / 放电 / 零功率 |
| 生命周期 | 停止 / 自检 / 预充 / 软启动 / 运行 / 故障 |

Buck/Boost 表示电压关系和调制区域，不等于充电/放电方向。在同步四开关拓扑中，同一调制区内也可能出现正电流或负电流。

## 5. 闭环控制与功率管理

### 5.1 分层结构

```text
功率管理层
车辆功率、母线限额、超级电容电压
        ↓ 生成有符号电流目标
电流控制层
电流 PI、电压前馈、限幅、抗积分饱和
        ↓ 生成调制指令
PWM 执行层
两桥映射、死区、比较寄存器、硬件关断
```

### 5.2 电流环

基础电流控制关系为：

$$
e_i=i_L^*-i_L
$$

$$
u_{PI}=K_pe_i+K_i\int e_i\,dt
$$

工程实现还要考虑电压前馈、输出限幅、抗积分饱和、电流参考斜率、采样延迟、数字计算延迟和环路带宽。

平均功率近似为：

$$
P_{bus}\approx V_{bus}D_Li_L,
\qquad
P_{cap}\approx V_{cap}D_Ri_L
$$

因此电感电流通常不等于母线端电流，也不等于超级电容端口电流。由功率换算电感电流时，需要考虑相应桥臂占空比。

### 5.3 不同模式的控制增益

Buck 区近似为：

$$
L\dot i_L=D_LV_{bus}-V_{cap}-R_Li_L
$$

Boost 区近似为：

$$
L\dot i_L=V_{bus}-D_RV_{cap}-R_Li_L
$$

控制输入对电感电流的增益分别与 $V_{bus}$、$V_{cap}$ 和调制坐标有关。跨越较大工作范围时，应检查同一组 PI 参数是否足够，必要时使用增益调度或不同工作区的补偿参数。

## 6. 预充、软启动与停机

### 6.1 生命周期状态机

建议至少考虑：

```text
OFF → SELF_CHECK → PRECHARGE → SOFT_START → RUN → STOPPING → OFF
                           任一适用状态发现严重故障 → FAULT
```

- `OFF`：PWM 关闭，输出处于已定义的安全状态。
- `SELF_CHECK`：检查 ADC、驱动器、电压和故障信号。
- `PRECHARGE`：处理初始电压差和浪涌电流。
- `SOFT_START`：逐步建立电感电流与功率。
- `RUN`：执行正常调制和闭环控制。
- `STOPPING`：先降低电流，再按安全时序关断。
- `FAULT`：锁存或管理故障，满足条件后才允许恢复。

这套状态是工程建议，当前 Python 模型没有完整实现。

### 6.2 预充与软启动的区别

预充处理功率通道接通前的初始电压差和浪涌；软启动在具备安全条件后逐渐建立电流、功率或电压目标。例如：

$$
i_L^*(t)=\operatorname{ramp}(0,i_{target},S_i)
$$

预充方案取决于硬件拓扑，可能使用预充电阻、受控 Buck 启动或其他限流路径。至少要分别分析超级电容完全放空、已有预偏置、母线掉电而电容带电、MCU 复位和故障后重启等工况。

## 7. 功率器件与硬件

### 7.1 元器件核算

| 元件 | 重点参数 |
|---|---|
| MOSFET | VDS、电流、RDS(on)、栅极电荷、开关损耗、SOA |
| 电感 | L、Isat、Irms、DCR、磁芯损耗、温升 |
| 母线电容 | 耐压、有效电容、ESR、纹波电流 |
| 超级电容 | 最高电压、ESR、容量、漏电、均衡要求 |
| 驱动器 | 高侧供电、UVLO、驱动能力、传播延迟、互锁 |
| 电流传感器 | 量程、带宽、零漂、延迟、共模能力 |
| MCU | PWM/ADC 同步、比较器、故障刹车、计算能力 |

近似对称三角纹波下，电感峰值电流可先估算为：

$$
I_{peak}=|I_{avg}|+\frac{\Delta I_{pp}}2
$$

还需加入暂态裕量，并确认饱和电流与保护门限的关系。

### 7.2 驱动、PCB 与热设计

硬件验证要覆盖高低侧互锁、死区续流路径、自举高侧驱动的刷新要求、开关环路面积、采样 Kelvin 连接、功率地与信号地、寄生振铃、MOS 和电感温升，以及传导和辐射 EMI。

## 8. 保护设计

| 层级 | 保护内容 | 执行方式 |
|---|---|---|
| 硬件快速保护 | 桥臂直通、严重过流、驱动欠压 | 驱动器、比较器、PWM 硬件关断 |
| 软件快速保护 | 过流趋势、母线异常、电容过压、采样异常 | PWM 同步中断或快速控制任务 |
| 系统级保护 | 过温、功率降额、预充超时、故障次数 | 状态机和故障管理器 |

不要让普通 1 ms 控制任务承担全部电感过流保护。例如电感两端出现 18 V、$L=150\,\mu H$ 时：

$$
\frac{di}{dt}=\frac{18}{150\,\mu H}=120000\ \mathrm{A/s}
$$

理想情况下每 10 μs 就可增加约 1.2 A。严重过流需要逐周期或更快的硬件关断通道。

故障时也不能不加分析地让所有 MOS 同时关断。电感电流不能突变，必须确认体二极管、寄生电容、母线钳位和吸收回路能够安全承受剩余能量。

## 9. 嵌入式软件架构

建议将职责分开：

- `PowerState` 决定是否允许运行以及所处生命周期阶段。
- `ModulationMode` 决定 Buck、Transition 或 Boost 调制约束。
- 有符号 `i_ref` 决定电流方向和大小。
- `Protection` 汇总硬件和软件故障，决定是否允许继续输出。

正常控制算法负责调节，严重故障由独立硬件快速通道处理。无需把调制模式、功率方向、生命周期和故障恢复全部塞进一个状态机。

### 10.2 验证矩阵

| 类别 | 必测内容 |
|---|---|
| 基本功能 | Buck、Boost、双向传输 |
| 启动 | 0 V 电容预充、预偏置启动、重启 |
| 模式切换 | Buck ↔ Transition ↔ Boost |
| 电流反向 | 充电 → 零电流 → 放电 |
| 动态控制 | 负载阶跃、功率阶跃、输入电压突变 |
| 异常保护 | 过流、过压、欠压、过温、传感器故障 |

模式切换时，应使用示波器同步观察 $V_{bus}$、$V_{cap}$、$i_L$ 和 PWM。只看最终平均电压，可能遗漏持续时间很短的危险峰值。
